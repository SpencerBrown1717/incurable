# Incurable?

Editorial site for [incurable.ai](https://incurable.ai). Branch `grok/editorial-site`.

`main` is still the static page Vercel serves with no build step. Do not replace it until this app builds on Vercel.

```
npm install
npm run build
```

The production build emits Nitro's Vercel output. The hall is a fully autonomous CRISPR and mRNA wet lab, 24/7/365, drawn to 173.6 football fields (Meta Hyperion, nearly 10 million sq ft). Assay data is sold to frontier labs. New drugs are designed to be manufactured at generic scale. Alzheimer's is the long mission, not a promise to be first. This is not a clinic.
